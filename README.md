# flue-canvas

A canvas application served via Cloudflare Workers for live-editing HTML pages with AI workflows.

## Development

```bash
pnpm dev    # Start the local development server
pnpm build  # Build client assets and compile for Cloudflare
pnpm push   # Run the push CLI helper
pnpm test   # Run integration tests
```

See [AGENTS.md](./AGENTS.md) for architecture, workflow details, and AI agents documentation.
